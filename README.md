# Wonderlust – Stay Booking Platform

Wonderlust is a full-stack web application inspired by Airbnb, developed as my major project for the Web Development course. The platform allows users to explore, list, and book unique places to stay while providing a seamless and responsive user experience.

The application enables property owners to create and manage listings, while travelers can browse accommodations, view detailed information, and make bookings. It also includes secure authentication, image uploads, reviews, and location-based features, making it a complete stay-booking solution.

## Features

- User authentication and authorization
- Create, edit, and delete property listings
- Browse and search available stays
- Property image uploads using Cloudinary
- Leave ratings and reviews
- Interactive maps for property locations
- Responsive design for desktop and mobile devices
- Secure backend with RESTful APIs

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- Bootstrap
- Cloudinary
- Mapbox/Leaflet (for maps)
- Passport.js (Authentication)
- Express Session & Flash Messages

## Purpose

The objective of this project was to gain hands-on experience in full-stack web development by building a real-world accommodation booking platform. It demonstrates concepts such as user authentication, CRUD operations, database design, REST APIs, image management, session handling, and deployment.
